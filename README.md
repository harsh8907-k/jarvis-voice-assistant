# Jarvis AI Voice Assistant

A Python-based personal assistant that accepts voice commands
and performs supported actions on Windows.

## Features
- Voice command recognition
- Text command mode
- Text-to-speech responses
- Website launching
- Extensible command system

## Requirements
- Python 3
- Microphone for voice mode

## Installation

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
